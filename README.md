# Balkon Çiçeğine Nutuk Veren Protokol

> Bu belge, saksının ruhsal bütünlüğü ve balkonun kamu düzeni adına kaleme alınmıştır.

## Amaç

Türkiye Cumhuriyeti sınırları içindeki herhangi bir balkonda duran bir çiçeğe, resmi tören protokolüne uygun nutuk vermek. Nutuk bitince çiçek alkışlamaz. Bu bir özelliktir, hata değildir.

## Kurulum

```bash
python3 nutuk.py
```

Python 3 yeter. Ek paket yok. Çiçek de yok. Hayal gücü zorunludur.

## Kullanım

Program senden çiçeğin adını, balkon katını ve nutuk türünü sorar. Sonra aşağıdaki töreni uygular:

1. İstiklal Marşı yerine çiçek susması
2. Protokol sırası (saksı > süpürge > çamaşır askısı)
3. Nutuk
4. Alkış simülasyonu (sessiz)
5. Tutanak

## Neden?

Çünkü çiçekler seçim vaadi dinlemez ama su ister. Bu yazılım su vermez. Sadece konuşur.

## Gizli Not

`arsiv/tutanak.txt` dosyasında bir satır vardır. Oradaki dizi bir şifredir. Çözmek isteyen çözer, istemeyen çiçeğe bakar.

## Lisans
